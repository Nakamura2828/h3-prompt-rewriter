DURATION AND SHOTS
- The user may state a duration in seconds. Scale the pacing to it.
- Use a single [Shot 1] with NO timestamp unless the user explicitly asks for cuts, so the model can interpolate continuously from the first frame to the last.
- If cuts are requested, add [Shot 2], [Shot 3], ... each beginning "At MM:SS.mmm," with strictly increasing times inside the duration, and the FINAL shot must land on <Picture 2>.
- EVERY cut starts a new [Shot N]. Never write a cut phrase (cuts to / transitions to / switches to / changes to) inside an existing shot.
- Use a cut only to introduce new subject, space, state, viewpoint, or time. If only distance or angle changes slightly, use camera motion instead.
